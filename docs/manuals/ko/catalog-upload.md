# 제품 카탈로그 일괄 업로드 가이드

> **대상 독자** — 서울아쿠아 사무실 직원 중 제품 마스터를 관리하는 담당자(MANAGER 이상)
> **대상 기능** — 사무실 앱 › 관리 › 제품 관리 › **카탈로그 CSV 업로드**
> **대상 파일** — 같은 화면의 **카탈로그 CSV 내보내기**로 받은 파일과 동일한 형식
> **문서 버전** — 2026-09-24 (v1)

---

## 0. 3줄 요약

1. 이 파일 한 장으로 **브랜드 · 제품군 · 모델 · 소모품 · 부속품 · 모델↔부품 연결**이 한 번에 등록됩니다.
2. 업로드는 **추가만 합니다.** 이미 있는 것은 건드리지 않고, 삭제도 수정도 하지 않습니다. 잘못 올린 값은 재업로드로 고쳐지지 않습니다.
3. 한 행은 **"모델 1개 × 부품 1개"** 입니다. 부품이 20개인 모델은 20행이 되고, 모델 정보는 그 20행에 똑같이 반복해서 씁니다.

---

## 1. 이 파일이 시스템에 만드는 것

업로드 한 번으로 아래 5종의 마스터 데이터와 2종의 연결이 생성됩니다.

| 시스템 항목 | 한 행에서 읽는 열 | 어디에 쓰이나 |
|---|---|---|
| **브랜드** | Brand | 제품 목록 필터, 향후 브랜드별 매출 집계 |
| **제품군(카테고리)** | Category (EN/KO/VI) | 제품 목록 분류, 고객 화면 표기(고객 언어로) |
| **모델** | Model Code, Product Name (EN/KO/VI), On Hand, Safety Stock, 가격 4종 | 계약·장비 등록 시 선택하는 기기 모델. 장비코드 `MAY-000001`이 모델별로 채번됨 |
| **소모품(필터)** | Part Type=`Consumable` 행의 Part SKU, Part Name, 주기 열 | 정기점검 시 교체·청소 대상 자동 추천, 필터 만기 알림 |
| **부속품** | Part Type=`Accessory` 행의 Part SKU, Part Name, Minor Part | 수리 시 사용 부품, 유·무상 판정 |
| **모델↔소모품 연결** | 같은 행의 Model Code + Part SKU + Quantity | 이 모델에 이 필터가 몇 개 들어가는지 |
| **모델↔부속품 연결** | 같은 행의 Model Code + Part SKU + Quantity | 이 모델에 이 부속품이 몇 개 들어가는지 |

## 2. 파일 규격

| 항목 | 규격 |
|---|---|
| 파일 형식 | **CSV만 가능** (`.csv`). Excel 파일(.xlsx/.xls)은 업로드 버튼이 받지 않습니다 |
| 문자 인코딩 | **UTF-8**. Excel에서 저장할 때 반드시 `CSV UTF-8(쉼표로 분리)` 형식을 고르세요 |
| 첫 행 | 반드시 **헤더 행**(열 이름). 데이터는 2행부터 |
| 열 순서 | 바뀌어도 됩니다. 시스템은 **열 이름으로** 찾습니다 |
| 열 이름 | 대문자/소문자는 상관없지만, 그 외 문자·띄어쓰기·괄호는 **정확히** 같아야 합니다 (`Model Code` ○ / `ModelCode` ✗) |
| 반드시 있어야 하는 **열** | `Brand`, `Category (EN)`, `Category (KO)`, `Category (VI)`, `Model Code` — 이 다섯 개 열이 없으면 파일 전체가 거부됩니다(값은 비어 있어도 됨) |
| 값 안에 쉼표가 있을 때 | 셀 전체를 큰따옴표로 감쌉니다: `"HEPA 필터 (AP-3008FH, 12개월)"`. Excel이 자동으로 해 줍니다 |
| 값 안에 큰따옴표가 있을 때 | 큰따옴표를 두 번 씁니다: `"세디먼트 필터 11"""` (11인치 표기). Excel이 자동으로 해 줍니다 |
| 빈 칸 | "값 없음"으로 처리됩니다. 공백 문자만 있는 칸도 빈 칸으로 봅니다 |
| 행 수 제한 | 없습니다. 다만 한 행씩 처리하므로 700행이면 수십 초 걸립니다. **완료 창이 뜰 때까지 브라우저 탭을 닫지 마세요** |

> 💡 **가장 안전한 시작 방법** — 제품 관리 화면에서 **카탈로그 CSV 내보내기**를 먼저 눌러 현재 데이터를 받고, 그 파일의 헤더 행을 그대로 쓰세요. 내보내기 형식과 업로드 형식은 동일합니다.

## 3. 행 구조 — "모델 × 부품 한 쌍"

한 행에는 **모델 정보(왼쪽 15열)** 와 **부품 정보(오른쪽 9열)** 가 함께 들어갑니다.

```
No. │ Brand │ Category(EN/KO/VI) │ Model Code │ Product Name(EN/KO/VI) │ On Hand │ Safety │ 가격 4종 ┃ Part Type │ Part SKU │ Part Name(EN/KO/VI) │ Quantity │ Replace │ Clean │ Minor
└──────────────── 모델 정보: 같은 모델의 모든 행에 똑같이 반복 ────────────────┘ ┗━━━━━━━━━━━━ 부품 정보: 행마다 다름 ━━━━━━━━━━━━┛
```

**예 — 필터 5개 + 부속품 2개를 가진 모델 `PTS-2100`** → 7행을 씁니다. 왼쪽 모델 정보 15개 열은 7행 모두 동일하게 반복하고, 오른쪽 부품 정보만 행마다 바꿉니다.

**부품이 하나도 없는 모델**(예: `GBD-1800` 무전원 비데) → 1행만 쓰고, `Part Type` 이후 오른쪽 열을 모두 비웁니다.

**같은 필터가 여러 모델에 쓰일 때**(예: `FLT-SED-11`은 20개 넘는 모델에 공통) → 모델마다 한 행씩 반복해서 씁니다. 필터 자체는 처음 한 번만 등록되고, 나머지 행은 "이 모델에도 붙는다"는 연결만 추가합니다.

## 4. 열별 상세

**필수** 열은 값이 비면 해당 항목이 만들어지지 않습니다. **선택** 열은 비워도 됩니다.

### 4-1. 모델 정보 열

| # | 열 이름 | 필수 | 시스템 반영 위치 | 빈 칸일 때 | 유의사항 |
|---|---|---|---|---|---|
| 1 | `No.` | – | **읽지 않음** | – | 사람이 보기 위한 일련번호. 아무 값이나 넣어도 되고 열 자체를 빼도 됩니다 |
| 2 | `Brand` | 선택 | 브랜드 마스터(브랜드명) | 브랜드 없는 모델로 등록 | **철자가 1글자라도 다르면 다른 브랜드가 새로 생깁니다.** `Seoul Aqua` / `SeoulAqua` / `seoul aqua`는 모두 다른 브랜드로 처리됩니다(대소문자도 구분) |
| 3 | `Category (EN)` | 필수* | 제품군 영어명 | 제품군 미지정 | *세 언어가 **모두** 채워져야 제품군이 붙습니다. 하나라도 비면 제품군 없이 모델만 생성됩니다 |
| 4 | `Category (KO)` | 필수* | 제품군 한국어명 | 〃 | 한국어 직원 화면 표기 |
| 5 | `Category (VI)` | 필수* | 제품군 베트남어명 | 〃 | 고객·기사 화면 표기 |
| 6 | `Model Code` | **필수** | 모델 코드(시스템 전체에서 유일) | 그 행의 모델·부품 연결이 모두 생성되지 않음 | 모델을 식별하는 **유일한 키**입니다. 같은 모델의 모든 행에 **완전히 동일하게** 적으세요. 앞뒤 공백은 자동 제거되지만 중간 공백·대소문자는 구분됩니다 |
| 7 | `Product Name (EN)` | 선택 | 모델 영문 제품명 | **모델 코드가 대신 들어감** | 모델 코드와 제품명이 같다면 비워도 결과가 같습니다 |
| 8 | `Product Name (KO)` | 선택 | 모델 한국어 제품명 | 〃 | |
| 9 | `Product Name (VI)` | 선택 | 모델 베트남어 제품명 | 〃 | 계약서·납품서 등 고객 문서에 쓰입니다 |
| 10 | `On Hand` | 선택 | 모델 현재고 (기초재고 이동 1건으로 기록) | `0` | 정수. 음수도 허용(부족 상태 기록). **소수점·쉼표 없이** 숫자만. 재고 원장에 "기초 잔고"로 남습니다 |
| 11 | `Safety Stock` | 선택 | 모델 안전재고(부족 경고 기준) | `0` | 0 이상 정수. 현재고가 이 값 아래로 내려가면 재고 화면에 경고가 뜹니다 |
| 12 | `Sale Price (VND)` | 선택 | 모델 판매가 | 미입력(빈 값) | **숫자만**. `8500000` ○ / `8,500,000` △(가능하지만 CSV에서 따옴표 필요) / `8.500.000₫` ✗ / `8500000 VND` ✗ |
| 13 | `Retail Price (VND)` | 선택 | 모델 소비자가 | 〃 | 견적·계약 기본 단가의 기준 |
| 14 | `Purchase Price (VND)` | 선택 | 모델 입고가(원가) | 〃 | 마진 계산용. 고객 문서에는 노출되지 않습니다 |
| 15 | `Dealer Price (VND)` | 선택 | 모델 지정가(대리점가) | 〃 | |

### 4-2. 부품 정보 열

| # | 열 이름 | 필수 | 시스템 반영 위치 | 빈 칸일 때 | 유의사항 |
|---|---|---|---|---|---|
| 16 | `Part Type` | **부품 등록 시 필수** | 부품 종류 구분 | 그 행의 부품은 무시(모델은 정상 생성) | **`Consumable`**(소모품·필터) 또는 **`Accessory`**(부속품) 둘 중 하나만 인식합니다. 대소문자는 무관하나 다른 단어(`부품`, `Filter`, `Part` 등)는 무시됩니다 |
| 17 | `Part SKU` | **부품 등록 시 필수** | 부품 코드(시스템 전체에서 유일) | 그 행의 부품은 무시 | 소모품과 부속품이 **같은 SKU를 쓸 수 없습니다**. 공백·대소문자까지 동일하게 반복해서 적으세요 |
| 18 | `Part Name (EN)` | 선택 | 부품 영문명 | **SKU가 대신 들어감** | |
| 19 | `Part Name (KO)` | 선택 | 부품 한국어명 | 〃 | 기사 앱·작업확인서에 표기 |
| 20 | `Part Name (VI)` | 선택 | 부품 베트남어명 | 〃 | 기사 앱·고객 문서 표기 — **베트남어 이름을 꼭 채우세요** |
| 21 | `Quantity` | 선택 | 이 모델에 들어가는 부품 개수 | `1` | 1 이상 정수. 0·음수·글자는 모두 `1`로 처리. 대형 제빙기처럼 필터가 2~4개 들어가면 그 숫자를 적습니다 |
| 22 | `Replace Every (days)` | 선택 | 소모품 교체 주기(**일** 단위) | 주기 없음 | **개월이 아니라 일수입니다.** 3개월=`90`, 6개월=`180`, 12개월=`360`, 18개월=`540`. 부속품 행에서는 무시됩니다 |
| 23 | `Clean Every (days)` | 선택 | 소모품 청소 주기(**일** 단위) | 주기 없음 | 숫자(일수) 또는 **`every visit`**(방문할 때마다 청소 — 프리필터가 여기 해당). `every visit`은 철자 그대로 영어로 적어야 인식됩니다 |
| 24 | `Minor Part` | 선택 | 부속품의 소액부품 여부 | `N`(유상 부품) | `Y`만 소액부품으로 인식. **유지관리 계약 고객에게 무상으로 교체해 주는 작은 부품**(코크·밸브·호스·피팅)은 `Y`, 금액이 큰 부품(콤프레샤·온수탱크·PCB)은 `N`. 소모품 행에서는 무시됩니다 |

> ⚠️ **교체/청소 주기는 반드시 "일" 단위입니다.** 예전 양식처럼 헤더를 `Replace Every (months)` / `Clean Every (months)`로 적으면 시스템이 개월로 읽어 30을 곱해 저장합니다. 두 양식을 섞지 마세요.

## 5. 중복 판정 규칙 — 무엇을 "같은 것"으로 보는가

업로드는 아래 키로 기존 데이터를 찾습니다. **찾으면 그대로 두고 연결만 추가**하고, 없으면 새로 만듭니다.

| 항목 | 같다고 판정하는 기준 | 주의 |
|---|---|---|
| 브랜드 | 브랜드명 완전 일치 | 대소문자·공백까지 구분 |
| 제품군 | (영어명, 한국어명, 베트남어명) **세 개 모두** 일치 | 한 언어만 달라도 새 제품군이 생깁니다. 예: `냉온정수기 — RO 방식`의 긴 대시(—)를 짧은 하이픈(-)으로 바꾸면 별개 제품군. 모델 하나가 **여러 제품군**에 속하면 세 칸 모두 ` \| `(세로줄)로 같은 순서로 이어 씁니다. 예: `Hot and cold water purifier \| RO` / `냉온정수기 \| RO` / `Máy lọc nước nóng lạnh \| RO`. 카탈로그 CSV 다운로드도 이 형식으로 나옵니다 |
| 모델 | 모델 코드 완전 일치 | |
| 소모품 | SKU 완전 일치 | |
| 부속품 | SKU 완전 일치 | |
| 모델↔부품 연결 | (모델, 부품) 조합 | 이미 연결돼 있으면 `Quantity`가 달라도 **갱신되지 않습니다** |

제품군 코드(영문 대문자 코드)는 영어 제품군명에서 **자동 생성**됩니다. 예: `Hot and cold water purifier (RO)` → `HOT_AND_COLD_WATER_PURIFIER_RO`. 직접 지정할 수 없습니다.

## 6. 절대 규칙 — "추가만, 수정 없음"

**이것이 이 기능의 가장 중요한 성질입니다.**

- ✅ 없는 브랜드·제품군·모델·부품·연결은 **새로 만듭니다.**
- ✅ 이미 있으면 **건너뜁니다**(중복 건수로만 보고).
- ❌ 기존 이름·가격·주기·재고를 **덮어쓰지 않습니다.**
- ❌ 파일에 없는 항목을 **지우지 않습니다.**

그래서 다음이 성립합니다.

| 상황 | 결과 |
|---|---|
| 같은 파일을 두 번 업로드 | 두 번째는 전부 "중복"으로 집계, 데이터 변화 없음 (안전) |
| 가격을 잘못 넣고 업로드한 뒤, 고쳐서 재업로드 | **반영되지 않습니다.** 제품 관리 화면에서 직접 수정해야 합니다 |
| 기존 모델에 필터를 추가하고 싶을 때 | 그 모델 코드 + 새 필터 행만 있는 작은 파일을 만들어 올리면 연결만 추가됩니다 |
| 필터 이름 오타를 고치고 싶을 때 | 재업로드로는 안 됩니다. 필터 마스터 화면에서 수정 |
| 가격·주기는 언제 반영되나 | **그 항목이 이 업로드로 처음 만들어질 때만** 반영됩니다 |

> ⚠️ 처리 도중 오류가 난 행은 **그 행만 건너뛰고 계속 진행**합니다. 전체 취소(롤백)는 없습니다. 즉 파일의 일부만 반영된 상태가 될 수 있습니다.

## 7. 작성 전 체크리스트

- [ ] 모델 코드가 같은 행끼리 **모델 정보 15개 열의 값이 완전히 동일**한가? (오타로 두 값이 섞이면, 먼저 나온 행의 값으로 등록되고 뒤 행은 무시됩니다)
- [ ] 제품군 세 언어가 **모두** 채워졌는가?
- [ ] 같은 제품군은 파일 전체에서 **똑같은 철자**인가? (대시·괄호·띄어쓰기 포함)
- [ ] 같은 SKU를 여러 모델에서 쓸 때, 이름·주기가 **모든 행에서 동일**한가? (다르면 처음 나온 행 기준으로만 등록됩니다)
- [ ] 한 SKU를 소모품과 부속품 양쪽으로 쓰지 않았는가?
- [ ] 주기를 **일 단위**로 적었는가? (개월 숫자를 그대로 넣은 `6`, `12` 같은 값 주의)
- [ ] 청소 주기의 `every visit`을 영어 철자 그대로 적었는가?
- [ ] 가격에 통화 기호·단위·마침표 구분자가 섞이지 않았는가?
- [ ] 부속품의 `Minor Part`를 `Y`/`N`으로 판단해 두었는가? (유지관리 고객 청구 금액이 달라집니다)
- [ ] 파일을 **CSV UTF-8**로 저장했는가?

## 8. 업로드 절차와 결과 읽기

1. 사무실 앱 › **관리 › 제품 관리** 로 이동합니다. (MANAGER 이상만 버튼이 보입니다)
2. **카탈로그 CSV 업로드** 버튼 → 파일 선택.
3. 처리 중에는 화면을 그대로 두세요. 700행 기준 수십 초가 걸립니다.
4. 완료되면 결과 요약이 뜹니다.

| 결과 항목 | 뜻 |
|---|---|
| 처리한 행 수 | 헤더를 제외한 데이터 행 수 |
| 신규 생성 — 브랜드/제품군/모델/소모품/부속품/연결 | 이번에 새로 만들어진 개수와 그 이름·코드 목록 |
| 중복 | 이미 있어서 건너뛴 개수 |
| 경고 | 문제가 있던 행. **행 번호는 CSV 파일의 실제 줄 번호**입니다(헤더가 1행). Excel에서 그 줄로 바로 가서 확인하세요 |

자주 보게 되는 경고:

- `Row 45: FLT-XXX has no replace/clean cycle — it will never be scheduled`
  → 교체·청소 주기가 하나도 없는 소모품입니다. 등록은 됐지만 **정기점검 추천·만기 알림에 절대 잡히지 않습니다.** 필터 마스터에서 주기를 채워주세요.
- `Row 120: Unique constraint failed ...` → SKU나 모델 코드가 다른 항목과 충돌했습니다.

## 9. 업로드 후 반드시 해야 할 마무리 작업

이 파일에 **담기지 않는** 값들이 있습니다. 업로드 후 화면에서 채워주세요.

| 채워야 할 값 | 어디서 | 왜 필요한가 |
|---|---|---|
| **소모품·부속품 가격** (소비자가/입고가/지정가) | 관리 › 제품 관리 › 필터·부속품 마스터 | 업로드로 만든 부품은 **소비자가가 0원**으로 등록됩니다. 유상 교체 청구액이 0원이 됩니다 |
| 소모품의 제품군·브랜드·규격·주요용도 | 필터 마스터 | 목록 검색·분류용 |
| 소모품·부속품 재고 수량 | 재고 관리 | 이 파일의 `On Hand`/`Safety Stock`은 **모델 재고에만** 반영됩니다 |
| 모델 점검 주기(정기점검 간격) | 제품 관리 › 모델 수정 | 정기점검 일정 자동 생성의 기준 |
| 모델 보증 개월 수 | 제품 관리 › 모델 수정 | 판매 고객 유·무상 판정 기준 |
| 월 렌탈료 / 월 관리비 | 제품 관리 › 모델 수정 | 렌탈·유지관리 계약 금액 |
| 필터 표시 순서 | 모델별 필터 구성 | 업로드된 필터는 모두 순서 0으로, 파일에 적힌 순서대로 정렬되지 않습니다 |

## 10. 자주 나는 문제와 대처

| 증상 | 원인 | 대처 |
|---|---|---|
| 업로드가 즉시 거부됨 — "필수 열 누락" | `Brand`, `Category (EN/KO/VI)`, `Model Code` 중 열 이름이 다르거나 없음 | 내보내기 파일의 헤더 행을 그대로 복사해 쓰세요 |
| 업로드가 거부됨 — "헤더 + 1행 이상 필요" | 빈 파일이거나 데이터 행이 없음 | |
| 한글·베트남어가 깨져서 등록됨 | CSV를 UTF-8이 아닌 형식으로 저장 | 엑셀에서 `CSV UTF-8(쉼표로 분리)`로 다시 저장 후 재업로드. **이미 깨져 들어간 행은 화면에서 직접 수정해야 합니다** |
| 같은 제품군이 두 개로 늘어남 | 세 언어 이름 중 하나의 철자가 달랐음 | 제품 관리에서 잘못된 제품군의 모델을 옮기고 빈 제품군을 비활성화 |
| 모델은 생겼는데 필터가 안 붙음 | `Part Type`이 `Consumable`/`Accessory`가 아니거나 `Part SKU`가 비었음 | 해당 행만 수정해 다시 올리면 연결이 추가됩니다 |
| 필터 만기 알림이 안 옴 | 교체·청소 주기가 비어 있음 | 필터 마스터에서 주기 입력 |
| 재고가 0으로 보임 | `On Hand` 열이 비었거나, 부품(소모품·부속품) 재고를 기대했음 | 부품 재고는 재고 관리 화면에서 입고 처리 |
| 가격이 반영 안 됨 | 그 모델이 **이미 등록돼 있던** 모델이었음 | 모델 수정 화면에서 직접 입력 |

## 부록 A. 작성 예시

**A-1. 필터 2개 + 부속품 1개를 가진 신규 모델**

| Brand | Category (EN) | Category (KO) | Category (VI) | Model Code | Product Name (KO) | On Hand | Safety Stock | Sale Price (VND) | Part Type | Part SKU | Part Name (KO) | Quantity | Replace Every (days) | Clean Every (days) | Minor Part |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| Seoul Aqua | Air purifier | 공기청정기 | Máy lọc không khí | CA-5000W | CA-5000W | 2 | 5 | 7200000 | Consumable | FLT-AIR-PREFILTER | 공기청정기 프리필터 | 1 | | every visit | |
| Seoul Aqua | Air purifier | 공기청정기 | Máy lọc không khí | CA-5000W | CA-5000W | 2 | 5 | 7200000 | Consumable | FLT-AIR-HEPA-6 | HEPA 필터 | 1 | 180 | | |
| Seoul Aqua | Air purifier | 공기청정기 | Máy lọc không khí | CA-5000W | CA-5000W | 2 | 5 | 7200000 | Accessory | ACC-ADAPTER-001 | 전원 어댑터 | 1 | | | Y |

- 모델 정보(브랜드~가격)는 3행 모두 동일 — 모델은 1개만 생성됩니다.
- 프리필터는 교체 주기 없이 `every visit` 청소 → 방문할 때마다 청소 대상으로 추천됩니다.
- 전원 어댑터는 `Minor Part = Y` → 유지관리 고객에게 무상 교체.

**A-2. 부품이 없는 모델**

| Brand | Category (EN) | Category (KO) | Category (VI) | Model Code | Part Type | Part SKU |
|---|---|---|---|---|---|---|
| Seoul Aqua | Non-powered manual bidet | 무전원 수동 비데 | Nắp vệ sinh thông minh không dùng điện | GBD-1800 | | |

**A-3. 제빙기처럼 같은 필터가 4개 들어가는 경우**

| Model Code | Part Type | Part SKU | Quantity | Replace Every (days) |
|---|---|---|---|---|
| FSM300 | Consumable | FLT-SED-11 | 4 | 90 |

`FLT-SED-11`은 다른 모델에서 이미 등록됐더라도 여기서는 **연결만** 추가되며, 이 모델에 한해 4개로 기록됩니다.
